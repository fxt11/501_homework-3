# Profile Picture with Notification Badge

## Project Description

This is an Android application developed using Jetpack Compose that demonstrates a circular profile picture component with a notification badge.

## Main Features

- **Circular Profile Picture**: Created using Card and CircleShape with shadow effects
- **Notification Badge**: Red badge aligned to the bottom-end corner using Box and Modifier.align(Alignment.BottomEnd)
- **Toggle Functionality**: Button to show/hide the notification badge
- **Status Display**: Real-time display of the badge's current state
